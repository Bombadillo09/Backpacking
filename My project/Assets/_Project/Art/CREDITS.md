# Art credits

## Ground textures

From [Poly Haven](https://polyhaven.com), released under [CC0](https://polyhaven.com/license) (public domain, no attribution required; listed here as thanks).

| Use | Texture | Author |
|---|---|---|
| Grass | [Leafy Grass](https://polyhaven.com/a/leafy_grass) | Charlotte Baglioni |
| Dirt | [Dirt Floor](https://polyhaven.com/a/dirt_floor) | eye-candy.xyz |
| Rock | [Aerial Rocks 02](https://polyhaven.com/a/aerial_rocks_02) | Rob Tuytel |
| Snow | [Snow 02](https://polyhaven.com/a/snow_02) | Rob Tuytel |
| Forest floor | [Forest Ground 01](https://polyhaven.com/a/forrest_ground_01) | Rob Tuytel |
| Alpine meadow | [Withered Grass](https://polyhaven.com/a/withered_grass) | Charlotte Baglioni |
| Leaf litter | [Forest Leaves 02](https://polyhaven.com/a/forest_leaves_02) | Rob Tuytel |
| Pine-needle litter | [Forest Ground 04](https://polyhaven.com/a/forest_ground_04) | Rob Tuytel, Rico Cilliers |

Each folder in `Ground/` holds the 2K diffuse and 1K OpenGL normal map. To swap one, replace the two JPGs (keeping the `<name>_diffuse.jpg` / `<name>_normal.jpg` naming) and run **Backpacking → Use Downloaded Ground Textures**.
